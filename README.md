# Project Title: RAN Network Simulator

## Description

RAN Network Simulator is an educational Roblox experience developed for the 2degrees ShadowTech programme. The project introduces Year 9–11 students to the basic concepts behind Radio Access Networks, mobile coverage, and 4G and 5G technology.

Players explore a simulated town containing mobile base stations, antennas, buildings, terrain, and different construction materials. Interactive signal heatmaps show how factors such as frequency, distance, obstacles, antenna direction, and material attenuation can affect mobile network coverage.

The experience includes activities involving 4G and 5G frequency bands, directional antenna beamforming, network coverage analysis, and material testing. Its goal is to make telecommunications concepts easier to understand through interactive visual demonstrations.

## Installation Instructions

First, create a Roblox account at:

https://www.roblox.com/CreateAccount

Clone the project repository into a folder on your computer using:

```bash
git clone https://github.com/Sujal-Chand/ran-simulation
```

Roblox Studio must also be installed. It is available for Windows and macOS from:

https://create.roblox.com/docs/studio/setup

Once the repository has been cloned, locate the Roblox place file included with the project.

## Usage Instructions

Open the project's `.rbxl` or `.rbxlx` file using Roblox Studio.

After the project has opened:

1. Select the **Home** tab at the top of Roblox Studio.
2. Click the blue **Play** button in the top-left area.
3. Wait for the player character and simulation environment to load.
4. Explore the town and interact with the available RAN demonstrations.
5. Use the frequency and network controls to observe changes in signal range, coverage, attenuation, and antenna behaviour.

The project can also be tested using Roblox Studio's multiplayer testing tools when testing server and client behaviour.

## Features

* Interactive 4G and 5G network demonstrations
* Signal-strength heatmap visualisation
* Directional antenna and beamforming simulation
* Frequency-based signal range
* Material attenuation testing
* Terrain and building obstruction simulation
* Player interaction zones
* Educational explanations of Radio Access Network concepts
* Support for common New Zealand mobile frequency bands
